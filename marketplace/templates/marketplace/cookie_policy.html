Cookie Policy

This page describes cookies and browser storage found in the current Ubhaar-Vyapaar codebase.

Current cookies and storage

Category What exists Purpose Loads before consent?
Strictly necessary Django session cookie Keeps users logged in and supports account workflows. Yes, when needed for account functionality.
Strictly necessary Django CSRF cookie/token Protects forms from cross-site request forgery. Yes, when forms are used.
Strictly necessary Cookie preference cookie Remembers whether optional analytics were accepted or rejected. Yes, after a user makes a cookie choice.
Analytics Google Analytics, only if configured and accepted Measures anonymous product usage such as marketplace search and quote-request flow events. No. It is not loaded before analytics consent.
Marketing None found in the current code audit. Not applicable. No.

The current code audit did not identify advertising pixels, embedded maps, video embeds, chat widgets, or social widgets.

Consent approach

Necessary cookies are required for login, forms, security, and remembering the cookie choice. Optional analytics are off by default and load only if a Google Analytics measurement ID is configured and the user accepts analytics.

If marketing or additional third-party embeds are added later, they should be placed behind an explicit consent mechanism and should not run before the relevant consent category is granted.
