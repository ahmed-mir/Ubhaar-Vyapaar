# Sample listing photography

These curated photographs are packaged as first-party static assets. The
existing Sample media resolver maps the stable `demo/listings/<filename>`
references to these files and keeps missing-file fallback first-party. Real
Manufacturer uploads continue to use the configured media storage.

All images were center-cropped to 16:9 at 1280 × 720 and re-encoded as WebP
(quality 82, metadata stripped) for predictable display and reasonable page
weight. The photos depict manufacturing subjects only; Sample companies and
listings remain fictional demonstrations.
